# موقع مؤسسة إدراك للتنمية، النسخة الإنتاجية

مشروع Astro ثنائي اللغة مدمج مع Pages CMS وContent Collections وصفحات ديناميكية.

## Cloudflare Pages
- Build command: `npm run build`
- Output directory: `dist`
- Node.js: 20 أو أحدث

## Pages CMS
افتح `https://app.pagescms.org` بعد رفع المشروع إلى GitHub. ملف `.pages.yml` موجود في الجذر.

## قبل الإطلاق
استبدل الشعار والصور والسجلات التجريبية، راجع بيانات الاتصال، واربط النماذج بخدمة آمنة. لا تُنشر قصص المستفيدين دون موافقة موثقة.
